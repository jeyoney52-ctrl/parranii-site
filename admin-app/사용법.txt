파르라니 관리 앱 — 처음 한 번만 하는 설치
==========================================

1) 구글 스크립트 바꾸기
   - 응답 시트(parranii 문의(응답)) → 확장 프로그램 → Apps Script
   - 기존 코드를 모두 지우고, 이 폴더의 tools\apps-script.gs 내용을 전부 붙여 넣고 저장
   - 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포   (‘새 배포’ 아님!)

2) 서버에 올리기
   - 이 폴더의 [배포하기.bat] 더블클릭
   - 처음이면 Cloudflare 로그인 창이 떠요 → 경단일지 때 쓰던 계정으로 로그인 → 허용
   - "관리 앱 비밀번호를 정해 주세요"가 나오면 4자 이상으로 정하기
   - 마지막에 나온 https://parranii-admin.○○○.workers.dev 주소를 메모

3) 핸드폰에 설치
   - 그 주소를 핸드폰에서 열기
     · 아이폰(사파리): 아래 공유 버튼 → 홈 화면에 추가 → 홈 화면의 ‘파르라니 관리’로 열기
     · 안드로이드(크롬): ⋮ → 홈 화면에 추가(또는 앱 설치)
   - 비밀번호로 들어가기 → [🔔 알림 켜기] → 허용 → 아래 [알림 테스트]

다음부터 고칠 게 생기면: 새 압축 파일을 이 폴더에 덮어쓰고 [배포하기.bat]만 실행 (비밀번호는 Enter로 건너뛰기)
